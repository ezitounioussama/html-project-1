# HTML Portfolio Page

A single-page personal portfolio built with HTML only — no CSS, no JavaScript. That constraint is
the exercise: the page has to be readable and correctly structured from its markup alone, so the
work goes into semantic elements and heading order rather than into styling.

Sections: hero, About Me, My Work, Resume, Contact Me.

Open `index.html` in any browser.
